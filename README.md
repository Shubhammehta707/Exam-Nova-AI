Exam Nova AI — Class 12 CBSE Quiz App

Exam Nova AI is an AI-powered educational quiz application designed to help Class 12 CBSE students prepare for their board examinations through interactive quizzes and practice questions.
Features
- Physics, Chemistry, and Mathematics quizzes
- AI-powered question generation, when configured
- Class 12 CBSE exam preparation
- Instant feedback on answers
- Quiz scores and performance tracking
- Interactive learning experience
- Mobile-friendly and responsive design
- Practice questions for board examinations

Getting Started
Prerequisites

Install Node.js and npm on your computer.
Installation

Clone the repository:
git clone https://examnovaai.netlify.app/

Navigate to the project folder:
cd boardace-ai-—-class-12-cbse-board-quiz

Install dependencies:
npm install

Start the development server:
npm run dev

Build the application:
npm run build


Deployment

This project can be deployed using Netlify.
1. Upload the project to GitHub.
2. Sign in to Netlify.
3. Import your GitHub repository.
4. Set the build command to npm run build.
5. Set the publish directory to dist.
6. Deploy the application.

Security
- Store secret API keys in environment variables.
- Never upload API keys to a public GitHub repository.
- Never expose private API keys in frontend code.
- Check AI provider usage limits and billing terms.
